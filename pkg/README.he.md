# עוזר אישי בוואטסאפ: מדריך הקמה

העוזר רץ על שרת קטן שרק שלך, מדבר איתך בוואטסאפ, ומחובר ל-OpenAI ול-Google (מייל, יומן ודרייב) שלך. השם, האופי והחיבורים שלך בלבד. אף אחד אחר לא רואה את המידע.

## מה צריך להכין (פעם אחת)
| מה | למה | כמה זמן | עלות |
|---|---|---|---|
| חשבון Hetzner + כרטיס אשראי | השרת | 5–10 דק׳ (לפעמים אימות זהות) | בערך 6€ לחודש |
| מספר טלפון נפרד לבוט (סים או eSIM) עם וואטסאפ | זה "הטלפון" של הבוט | תלוי בספק | לפי הספק |
| חשבון OpenAI עם קרדיט | המוח | 5 דק׳ | לפי שימוש (מתחילים ב-10–20$) |
| חשבון Google | מייל, יומן ודרייב | 10 דק׳ (מדריך מובנה) | חינם |

בסך הכול לוקח בערך 30–45 דקות, וכולל 5–8 דקות שבהן השרת מתקין את עצמו לבד.

## הדרך הקלה: אשף ההקמה
1. **Hetzner (שלב 0):** פותחים את אתר ההקמה, נרשמים ל-Hetzner, יוצרים פרויקט ו-API token עם הרשאת Read & Write, ומדביקים אותו. האתר יוצר לך שרת (CX23, Ubuntu 24.04) שמתקין את הכל לבד. הטוקן לא נשמר. אחרי ההקמה אפשר למחוק אותו.
2. **פרטים:** שם לבוט, אופי, השם שלך, מספר הוואטסאפ **שלך**, ואם רוצים גם בן/בת זוג שיכולים לנהל איתך.
3. **וואטסאפ:** בטלפון מקבלים קוד חיבור ומקלידים אותו בוואטסאפ של **מספר הבוט**: הגדרות ← מכשירים מקושרים ← קישור מכשיר ← "קישור באמצעות מספר טלפון". במחשב אפשר פשוט לסרוק QR.
4. **OpenAI:** טוענים קרדיט, יוצרים מפתח ומדביקים אותו. הדף בודק אותו בלי עלות. אפשר גם לקבוע תקרת הוצאה חודשית.
5. **Google:** פעם אחת יוצרים "מפתח חיבור" (OAuth Client) בחשבון שלך לפי המדריך שבדף (`docs/google-oauth.he.md`), ואז לוחצים "חבר את Google".
6. **סיום:** שולחים לבוט הודעה מהוואטסאפ הפרטי שלך.

את הקישור לדף החיבורים שומרים. דרכו מחברים מחדש כל דבר (למשל מחליפים מספר וואטסאפ או מפתח). אם הקישור אבד, מריצים בשרת `sudo agentctl link`, ואם צריך קישור חדש, `sudo agentctl new-link`.

## הדרך הידנית (בלי אתר ההקמה)
1. ב-Hetzner: Create server ← Ubuntu 24.04 ← CX23. בשדה **Cloud config** מדביקים את `deploy/cloud-init.yaml`, אחרי שממלאים בו את קישור החבילה וסיסמה אקראית ארוכה משלך.
2. אחרי 5–8 דקות פותחים את `https://<IP-עם-מקפים>.sslip.io/?t=<הסיסמה>`.
3. אפשרות נוספת: מתחברים לשרת ב-SSH, פורסים את החבילה ומריצים `sudo bash install.sh`. בסוף ההתקנה יודפס הקישור.

## מה מותקן
- `/opt/agent`: הקוד, `.env` (ההגדרות, הרשאה 600), `data/` (זיכרון ומסמכים), `logs/`, ו-`wa-bridge/` (חיבור הוואטסאפ).
- שירותים: `assistant-bridge` (וואטסאפ), `assistant-setup` (דף ההגדרות), `assistant-bot` (הבוט), ו-`caddy` (HTTPS אוטומטי).
- פקודות: `agentctl status`, `agentctl logs`, `agentctl restart`, `agentctl link`.
- הזיכרון מתחיל ריק לגמרי, ומסד הנתונים נוצר בהפעלה הראשונה.

## שאלות נפוצות
- **Google מתנתק אחרי שבוע?** צריך ללחוץ Publish app (In production) בדף ה-Audience, כמו שמוסבר במדריך.
- **"Google hasn't verified this app"?** זה צפוי, כי זו אפליקציה שיצרת בעצמך. לוחצים Advanced ואז Go to….
- **Hetzner לא נותן ליצור שרת?** לחשבונות חדשים יש לפעמים מגבלה זמנית. מנסים שוב מחר.
- **כמה זה עולה?** השרת עולה בערך 6€ לחודש. OpenAI תלוי בשימוש, והתקרה שקבעת עוצרת את הבוט כשמגיעים אליה.
- **גיבוי:** כדאי לגבות מדי פעם את `/opt/agent/data` ואת `/opt/agent/.env`.
