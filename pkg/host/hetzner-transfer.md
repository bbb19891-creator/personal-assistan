# העברת השרת לפרויקט שלך

זה קורה במסך של Hetzner. אין כאן מפתח ואין מה להדביק.

## אתה מזמין את בעל הפרויקט הנוכחי

1. נכנסים לקונסולה של Hetzner.
2. פותחים את הפרויקט שלך, זה שאליו השרת צריך לעבור.
3. בתפריט הצד בוחרים Security.
4. פותחים את הלשונית Members.
5. לוחצים Add member.
6. מזמינים את בעל הפרויקט הנוכחי כחבר בפרויקט.

## בעל הפרויקט הנוכחי מעביר את השרת

1. מקבלים את ההזמנה ונכנסים לפרויקט שלך.
2. חוזרים לפרויקט שבו השרת נמצא עכשיו.
3. פותחים את השרת.
4. בוחרים Transfer to Project.
5. בוחרים את הפרויקט שלך ומאשרים.

אחרי זה השרת נמצא רק בפרויקט שלך.
